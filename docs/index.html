Move from question to action.

Crew brings analytics, product judgment, and recurring growth workflows into one self-hosted workspace.

01

Three ways to use Crew

Run commands directly, work with an agent, or run a repeatable workflow.

Command mode

Run known commands

List metrics, compile SQL, review experiments, and find saved artifacts with deterministic CLI commands.

$ crew metrics list
$ crew experiment list
$ crew artifact search "launch readiness"
METRICS · EXPERIMENTS · ARTIFACTS
Agent mode

Work through an open question

The Data Agent chooses the analytical path and brings in PM or Growth judgment when the question needs it.

$ crew repl
$ crew repl --session-id <id>
$ crew browse
ANALYZE · EXPLAIN · COLLABORATE
Workflow mode

Run repeatable work

Use typed, auditable workflows for recurring tasks that should produce the same durable result every time.

$ crew workflow run consumption-dip
$ crew workflow run expansion-pqa
$ crew workflow status <run_id>
SCHEDULED · DURABLE · RETRYABLE

02

The two workflows

Retention and expansion are the two ways to move NRR. Both workflows use a deterministic candidate selection, augmented with a Growth agent for reasoning.

workflow 1a Daily · addresses consumption dips

Consumption Dip Rescue

Consumption can decline before the account sends an explicit signal. The workflow measures the change and gives the Growth Agent a complete account snapshot.

select_play_candidatescodewarehousecrm_db

Compute decay vs. the account's own baseline, apply fixed gates, attach account context, and persist the run's candidate snapshots.

curate_playsagentconsumption-dip skill

Group every selected account by the action it needs and draft evidence-based reusable copy in one reasoning pass.

commit_playscodeplay tablesartifact

Validate full coverage and copy values, commit plays plus assignments atomically, and render the briefing. Idempotent and retryable.

Output A ranked retention briefing backed by the exact candidate rows and committed play assignments.
workflow 1b Weekly · drives the expansion

Expansion / PQA Engine

Usage shows which accounts are growing. Account context shows how much room they have and whether the timing is strong. The Growth Agent uses both to choose the motion.

select_play_candidatescodewarehousecrm_db

Compute the raw PQA score, exclude open opportunities, attach company context, and persist the run's candidate snapshots.

curate_playsagentexpansion-pqa skill

Compare usage growth with company size and timing, then group accounts into self-serve nudges or sales briefings with grounded copy.

commit_playscodeplay tablesartifact

Run the same validation, atomic persistence, assignment, and artifact rendering path as Consumption Dip.

Output A ranked expansion briefing backed by the exact candidate rows and committed play assignments.

The workflows commit candidate sets, play definitions, assignments, and briefing artifacts. They do not send outbound, route live rep tasks, assign holdouts, or update account theses.
